Timesheet Automation for Contractors

Specialty Electrical Contractor

Build time: 8 days | Production: active | Complexity: high

The Problem

A specialty electrical contractor employed 20+ union electricians across multiple job sites. Each week, timesheets had to be:

  • Collected from field staff (sometimes via phone, sometimes on paper)
  • Reviewed for union rules compliance (different unions have different work hour rules, overtime thresholds, classifications)
  • Matched to job codes and customer accounts
  • Classified by apprentice/journeyman/foreman (different pay rates)
  • Calculated for overtime (complex: some unions use 8-hour daily; others use weekly thresholds)
  • Entered manually into payroll software
  • Verified for payroll accuracy

This process took 15–20 hours every two weeks and required deep institutional knowledge about union rules, site assignments, and payroll logic.

Why Off-the-Shelf Tools Failed

Timesheet software exists (ADP, Guidepoint, etc.), but none of it handles the complexity here: multiple unions with different rules, job-site specific classifications, complex overtime calculations, and field collection methods. The contractor had tried three commercial solutions before reaching out to us. Each one required so much manual workaround that they went back to spreadsheets.

The Solution

We built a custom system that:

  • Receives timesheet data from field staff (via phone, email, or field app)
  • Automatically applies the correct union rules for each electrician
  • Classifies hours by apprentice/journeyman/foreman based on job assignment and seniority
  • Calculates overtime using the union's specific rules (daily vs. weekly thresholds)
  • Flags exceptions (hours exceeding union limits, unclassified staff, missing job codes) for manual review
  • Exports clean data directly to payroll software
  • Stores historical data for auditing and future analysis

The key innovation: We didn't build a template system. We built a rules engine that codified every union's specific logic. We consulted with the owner to document all the edge cases and exceptions. Then we built a system that handles 95% of cases automatically — and flags the remaining 5% for human review.

The Build: Complex But Worth It

Why It Took Longer

Timesheet automation is harder than it sounds. We spent 3 days in diagnosis: understanding union rules, learning how the contractor assigns jobs, documenting edge cases. We found 12+ scenarios that a template solution would have missed.

Build took 5 days. Testing and validation took another 3 (payroll errors are expensive, so we had to be thorough).

What We Built

A system that:

  • Reads incoming timesheet data from multiple sources
  • Looks up each electrician's current job assignment and classification
  • Applies the correct union rules for their jurisdiction
  • Calculates pay and overtime
  • Validates against constraints (union rules, job budgets, contractor policies)
  • Exports to QuickBooks and ADP Payroll
  • Sends the contractor a summary report and flags exceptions

Ongoing Operation

The system runs automatically every Friday evening. Staff reviews the report (now 30 minutes instead of 15–20 hours). The contractor verifies the numbers and submits to payroll. No manual data entry.

When union rules change or new staff joins, we update the system. The contractor never has to re-learn the manual process.

The Real Impact

Before: One person was responsible for timesheets. If they were sick, they had to work from home. The process was bottleneck risk.

After: Timesheets run automatically. The contractor spot-checks them. No single-person dependency. The knowledge is documented in the system.

Additionally: The historical data now gives the contractor insight into cost per job, labor efficiency trends, and overtime patterns. That intelligence is valuable for bidding and resource planning.
